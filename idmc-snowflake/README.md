# IDQ &rarr; Snowflake: procedure documentation

One page per Snowflake stored procedure of [`idq-to-snowflake/`](../idq-to-snowflake/README.md), generated by `ext-tools/snowflake_spec.py` from the procedure headers. Each page says what the procedure does, its validations, its bad-data handling and its MDM timeline logic (all in scope for this port), its parameters, the tables it writes and the shared functions it calls. The IDQ / CDI specification of the same mapping is in [`idmc/`](../idmc/).
